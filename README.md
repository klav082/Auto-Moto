AutoMoto

AutoMoto is an AI-powered Integrated Development Environment (IDE) developed to support AUTOSAR-based projects. It provides an easy-to-use interface that helps developers create, configure, and manage AUTOSAR applications more efficiently.

AUTOSAR mainly uses ARXML (AUTOSAR XML) files, which store information about software components, configurations, and their connections in an automotive system. AutoMoto makes working with these files easier by allowing users to view, edit, validate, and generate ARXML files without dealing with complex manual processes.

One of the most interesting features of AutoMoto is its use of Artificial Intelligence. Instead of writing ARXML files manually, users can describe the required configuration in simple English, and the tool automatically generates the corresponding ARXML file. This saves time and makes the development process faster and more convenient.

Features of AutoMoto
1. Displaying Basic Software Module Definitions (BSWMD)

The tool reads the Basic Software Module Definitions (BSWMD) used in AUTOSAR and presents them in a clear and organized format, making them easier to understand and navigate.

2. Parsing ARXML Files

AutoMoto can open and parse ARXML files. The extracted information is displayed in a structured and user-friendly interface, allowing users to easily explore the file contents.

3. Editing and Exporting ARXML Files

Users can upload existing ARXML files, make the required modifications, and export the updated version. This simplifies the process of maintaining and updating AUTOSAR configurations.

4. ARXML Validation

The tool includes a validation feature that checks whether:

The ARXML file follows the correct AUTOSAR XML schema.
The XML structure and hierarchy are valid.
The file is free from common formatting and configuration errors.
5. Generating C and Header Files

AutoMoto can generate the corresponding C (.c) and Header (.h) files from ARXML configurations. These files can then be used during ECU software development.

6. AI-Based ARXML Generation

A unique feature of AutoMoto is its ability to generate ARXML files from plain English instructions. Users simply describe the required configuration, and the AI model converts the description into a valid ARXML file, reducing manual effort and improving productivity.
